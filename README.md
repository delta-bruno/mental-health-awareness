# 🌿 MindCare Hub

A calm, supportive mental health website built with **HTML**, **CSS**, and **JavaScript**. MindCare Hub offers thoughtful resources across emotional wellness, stress relief, self-care, spirituality, and guided reflection.

---

## ✨ Project Highlights

- **Modern responsive design** for desktop, tablet, and mobile.
- **Soft calming palette** featuring green, blue, and white tones.
- **Supportive content pages** for mood-based mental health needs.
- **Interactive tools** like chat support, breathing exercises, quote generators, and journaling.
- **Dark mode** with preference saved in `localStorage`.
- **Video library** with direct watch links and fallback support.

---

## 📁 Included Pages

| Page | Purpose |
|---|---|
| `index.html` | Home page with mood selector and navigation cards |
| `sad.html` | Sadness support with quotes and encouragement |
| `stressed.html` | Stress relief guidance and breathing exercise |
| `anxious.html` | Anxiety coping tools and grounding tips |
| `sleep.html` | Sleep hygiene tips and relaxation content |
| `study-pressure.html` | Study balance, time management, and motivation |
| `motivation.html` | Daily encouragement and success tips |
| `relaxation.html` | Relaxation gallery, breathing guides, and music/video support |
| `faith.html` | Faith & prayer encouragement with scriptures and worship video |
| `videos.html` | Curated support video categories |
| `chat.html` | Support chat with empathetic responses and crisis guidance |
| `journal.html` | Reflection journal saving entries with local storage |

---

## 💡 Features

- **Mood-based navigation**: select a mood and jump to the right support page.
- **Positive quote system**: random quotes for encouragement and reflection.
- **Support chat**: keyword-aware empathetic responses and caring guidance.
- **Journal storage**: save, view, and delete reflections with local storage.
- **Fallback video links**: if embeds fail, users can open the video directly on YouTube.

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

All pages are built without frameworks, keeping the experience lightweight and easy to customize.

## 🚀 How to Use

1. Open `index.html` in your browser.
2. Navigate using the top menu or mood selector.
3. Explore support pages, videos, chat, and journaling.

> MindCare Hub is designed for supportive information and positive reminders, not as a replacement for professional mental health care.
